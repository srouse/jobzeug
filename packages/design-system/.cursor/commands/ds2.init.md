# ds2 init

Bootstrap DS2 in the current project. Prompts for AI environment selection.

## Usage

```
ds2 init [--ai cursor|claude] [--json]
```

## When to use

Run this command once in a new project to install DS2 commands and skills.

## Flags

- `--ai cursor` — Install Cursor commands to `.cursor/commands/`
- `--ai claude` — Install Claude commands to `.claude/commands/`
- `--json` — Output result as machine-readable JSON
