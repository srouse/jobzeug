# ds2 update

Update DS2 command and skill files to match the latest package version.

## Usage

```
ds2 update [--dry-run] [--json]
```

## When to use

Run after upgrading the `ds2` package to sync installed files to the new version.

## Flags

- `--dry-run` — Preview what would change without writing any files
- `--json` — Output result as machine-readable JSON
