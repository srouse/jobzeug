# Session token fonts

Curated catalog for the Design-tab session override. The agent may only set `fontFamily` to a name listed here (plus local stacks below).

- **Local** — already available; no network load.
- **Google** — loaded on Apply via `fonts.googleapis.com` (session only).

Feel lines are short design notes (not official Google blurbs). Prefer sans for UI body; save display/handwriting for accents.

Source metadata: [fontsource/google-font-metadata](https://github.com/fontsource/google-font-metadata) (categories/weights). Generated for Jobzeug session tokens.

## Notes for the design agent

- Pick **one** `fontFamily` for the whole session flood (all type roles share it today).
- Brand mimic: map scraped face to the **closest** name in this file; mention remap in the summary.
- Handwriting/display: only when the user asks for that vibe — not for dense resume UI by default.
- Exact spelling matters (e.g. `Source Sans 3`, `Plus Jakarta Sans`, `EB Garamond`).
